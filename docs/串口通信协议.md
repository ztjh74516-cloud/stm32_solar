# 串口通信协议

本协议描述 STM32 固件与 `上位机/` PyQt 程序之间的 UART 文本通信。上位机默认使用 `115200` 波特率。

## 串口参数

| 参数 | 值 |
| --- | --- |
| 波特率 | 115200 bps |
| 数据位 | 8 |
| 校验 | 无（N） |
| 停止位 | 1 |
| 编码 | UTF-8/ASCII 兼容文本 |
| 行结束符 | `\r\n` |

## 下位机上报

固件以逗号分隔的 `键:值` 文本行上报遥测数据；当前主循环约每 500 ms 上报一次。

```text
V:5.24, I:129, OUT_V:5.18, OUT_I:129, SH:1290, P:675, TH:10.00, RLY:ON\r\n
```

| 字段 | 含义 | 单位/取值 |
| --- | --- | --- |
| `V` | 输入电压 | V |
| `I` | 输入电流 | mA |
| `OUT_V` | 继电器输出侧电压 | V |
| `OUT_I` | 继电器输出侧电流 | mA |
| `SH` | INA219 分流采样原始值 | 整数计数值 |
| `P` | 输入功率 | mW |
| `TH` | 保护电压阈值 | V |
| `RLY` | 继电器状态 | `ON` 或 `OFF` |

上位机兼容不含 `OUT_V`、`OUT_I` 的旧格式：当继电器为 `ON` 时，会使用输入侧数值作为输出侧数值；当继电器为 `OFF` 时，输出侧按 0 处理。

## 上位机下发命令

上位机向下位机发送一个十进制电压值，并自动追加 `\r\n`。下位机将其解析为保护阈值。

```text
5.00\r\n
```

| 规则 | 说明 |
| --- | --- |
| 取值范围 | `0.00`–`25.00` V，超出范围的值会被下位机忽略。 |
| 精度 | 上位机按两位小数发送。 |
| 保存 | 有效值会写入 STM32 备份寄存器，重启后恢复。 |
| 反馈 | 下位机后续遥测行中的 `TH` 字段反映当前阈值。 |

## 调试建议

- 使用 USB-TTL 时，交叉连接 TX/RX，并与 STM32 共地。
- 保持串口为 115200、8N1；错误的波特率会导致上位机无法解析完整行。
- 串口终端页面会显示收到的原始文本，可用于排查字段名、单位或行结束符问题。
