# 硬件连接说明

本说明依据当前固件源码整理。接线或模块型号变更后，请同步修改本文档及对应的 `Hardware/` 驱动文件。

## 主控与调试

- 主控：STM32F103C8。
- 程序时钟配置以 12 MHz 外部时钟为基础；调试/烧录接口由所使用的 ST-Link 或 J-Link 连接。
- 所有与 STM32 相连的 GPIO 信号必须满足 STM32F103 的 3.3 V 电平要求。

## 引脚表

| STM32 引脚 | 连接模块/信号 | 固件用途 | 备注 |
| --- | --- | --- | --- |
| PA0 | 光伏输入电压分压输出 | ADC1 通道 0 | 固件按 3.3 V 参考电压和 5 倍分压倍率换算；输入不得超过 ADC 允许范围。 |
| PA1 | 低电平触发继电器输入 | 继电器控制 | 低电平吸合、高电平释放；代码使用开漏输出。 |
| PA9 | USB-TTL 的 RXD | USART1 TX | 波特率 115200，8N1。 |
| PA10 | USB-TTL 的 TXD | USART1 RX | 与 USB-TTL 共地。 |
| PB6 | OLED SCL、INA219 SCL | 软件 I²C 时钟 | 两个模块共用同一条软件 I²C 总线。 |
| PB7 | OLED SDA、INA219 SDA | 软件 I²C 数据 | 两个模块共用同一条软件 I²C 总线。 |
| PB10 | 蜂鸣器控制 | 报警输出 | 当前代码为低电平响。 |
| PB11 | 报警 LED 控制 | 报警输出 | 当前代码为高电平亮。 |
| PB12 | SET 按键 | 设置模式切换 | GPIO 内部上拉，按键另一端接地，低电平有效。 |
| PB13 | UP 按键 | 增大阈值 | GPIO 内部上拉，按键另一端接地，低电平有效。 |
| PB14 | DOWN 按键 | 减小阈值 | GPIO 内部上拉，按键另一端接地，低电平有效。 |

## I²C 模块

- OLED 驱动向地址 `0x78` 写数据，对应常见 7 位地址 `0x3C`。
- INA219 驱动使用 8 位地址 `0x80`，对应默认 7 位地址 `0x40`。
- 两个模块可并联至 PB6/PB7；总线需要适当的上拉。很多模块已自带上拉电阻，避免重复并联导致上拉过强。
- 代码采用软件 I²C，并且不检查从机 ACK；接线错误或地址不同会导致读数无效而不一定出现明确的软件错误。

## 供电与安全

- STM32 GPIO 不可直接承受 5 V。若继电器模块的控制端上拉到 5 V，必须确认其输入电路与开漏控制方式兼容，不能把 5 V 直接送入 PA1。
- 光伏电压必须先经过可靠的分压/隔离电路后再接 PA0；根据实际电阻比修正 `Hardware/PV_Monitor.h` 中的 `VOLTAGE_SENSOR_RATIO`。
- INA219 应串联在待测电流路径中，注意模块量程、分流电阻发热、极性和公共地连接。
- 首次上电前，先断开功率侧负载，使用万用表确认 MCU 电源、分压输出和各控制信号的电压。

## 已知引脚关系

`Hardware/LED.c` 将 PA1、PA2 定义为普通 LED 输出，但当前主程序未调用 `LED_Init()`，并把 PA1 用作继电器控制。因此 PA1 应保留给继电器；如需启用 `LED.c`，请先调整其引脚定义，避免与继电器冲突。
